# 논문값과 재현값이 다른 이유: 확인된 원인

DLinear 논문(Zeng et al., AAAI 2023)의 표를 공식 코드(cure-lab/LTSF-Linear)로 재현했을 때 생긴 차이를 원인별로 정리한다. 여기에는 실험으로 직접 확인한 것만 적는다. 아직 설명하지 못한 차이는 `open_problems.md`에 따로 있다.

- 작성일: 2026-11-13
- 실험 환경: Colab T4(GPU), CPU 전용 환경(PyTorch 2.x), 일부는 PyTorch 1.9.0
- 원자료: 이 폴더의 CSV 파일. 각 절 끝에 파일 이름을 적었다.

| 구분 | 지금 코드 | 2022-06 코드 |
|---|---|---|

노란 5칸은 Traffic 4칸(0.001~0.002 차이)과 ETTm2 96(0.1677 대 0.167)이다. ETTm2 720과 독감 4칸은 2절의 학습률을 적용한 값이다.

## 2. 스크립트의 학습률이 논문 이후에 바뀌었다

| 칸 | 2022-06 스크립트 | 2022-08 스크립트 | 논문값이 나오는 설정 |
|---|---|---|---|
| ETTm2 720 | 0.1 | 0.01 (2022-08-22 `726695f`) | 2022-06 코드 + 학습률 0.01 → 0.3971 / 0.4211 (논문 0.397 / 0.421) |
| 독감 24·36·48·60 | 0.05 | 0.01 | 2022-06 코드 + 학습률 0.01 → 2.2149 / 1.9628 / 2.1295 / 2.3684 (논문 2.215 / 1.963 / 2.130 / 2.368) |

즉 논문 최종본(2022년 8월)의 DLinear 열은 "2022-06 코드 + 일부 칸만 새 학습률"로 만들어진 것으로 보인다. 2022-06 스크립트 그대로 돌린 독감 값(2.108 / 2.332 / 2.088 / 2.299)은 2022년 6월 README 표와 일치한다.

2022-08 코드와 스크립트로 DLinear를 돌리면 ETTh1 192는 0.4434, 환율 720은 0.8976이 나온다. 처음 재현값(0.443, 0.898)과 같다. 1절에서 남았던 두 칸의 차이는 2022-08 스크립트의 학습률로 설명된다.

원자료: `../paper_era_ett.csv`, `../paper_era_colab.csv`, `aug2022_code_linear_nlinear_dlinear.csv`

## 3. 테스트의 마지막 배치를 버리는 방식

2023-03-15 이전 코드는 테스트에서 배치 크기에 못 미치는 마지막 묶음을 버렸다. 지금 코드는 버리지 않는다. 1절 표의 "채점만 바꿈" 열이 이 효과다. 6칸에서 가장 큰 차이가 환율 336의 0.005이고 나머지는 0.002 이하다. 빨간 칸의 주된 원인은 아니다.

이 방식은 저자들도 issue #58에서 인정하고 고쳤다. TFB 벤치마크 논문(PVLDB 2024)은 이 방식이 배치 크기에 따라 결과를 바꿔 불공정한 비교를 만든다고 지적한다.

## 4. Traffic 96은 더 길게 학습한 값이다

2022-06 코드, 스크립트 설정(학습률 0.05, 배치 16) 그대로 돌린 결과다.

| 설정 | MSE | MAE |
|---|---|---|
| 논문 | 0.410 | 0.282 |
| 시드 2021, 최대 10 epoch (기본값) | 0.4112 | 0.2839 |
| 시드 2022, 최대 10 epoch | 0.4118 | 0.2854 |
| 시드 2023, 최대 10 epoch | 0.4123 | 0.2872 |
| 시드 2021, 최대 30 epoch (16번째에서 조기 종료) | 0.4103 | 0.2822 |

- 기본 설정은 10 epoch에서 강제로 끝나는데, 그 시점에도 검증 오차가 줄고 있었다. 상한을 30으로 늘리면 16번째 epoch에서 조기 종료하고 MSE·MAE 모두 논문과 일치한다.
- 시드를 바꾸면 논문값에서 멀어진다. 시드는 원인이 아니다.
- CPU에서 돌린 값(0.4112 / 0.2839)이 Colab T4 값과 같다. 하드웨어 차이도 아니다.
- 공개 스크립트에는 epoch 수가 적혀 있지 않고, 스크립트 자체는 첫 공개 이후 바뀐 적이 없다.

192·336·720은 같은 방법으로 아직 확인하지 못했다(`open_problems.md` 1번).

원자료: `traffic96_june2022_code.csv`, `traffic96_epoch_curve.csv`

## 6. 논문 Table 9의 단변량 ETTh1 720은 오타다

- 논문 Table 9: DLinear ETTh1 720 = 0.189 / 0.359. 같은 줄 Linear의 96 칸도 0.189 / 0.359로 똑같다.
- 2022년 6월 README 표: DLinear ETTh1 720 = 0.119 / 0.274.
- 2022-06 코드로 재실행: 0.1186 / 0.2741.

재실행 값이 README 표와 일치한다. 논문 표의 값은 옆 칸을 잘못 옮긴 것으로 보인다.

## 7. 공식 LTSF-Benchmark.md의 행 이름이 바뀌어 있다

저장소의 `LTSF-Benchmark.md` 둘째 표(전력, 환율, 교통, 날씨, 독감)에서 "DLinear"라고 적힌 행에 논문의 NLinear 값이, "NLinear"라고 적힌 행에 논문의 DLinear 값이 들어 있다. 예를 들어 독감 24의 2.215와 환율 96의 0.081은 논문에서 DLinear 값인데, 이 표에서는 NLinear 행에 있다. 첫째 표(ETT 4종)는 정상이다. 이 표로 재현값을 대조할 때는 두 행을 바꿔서 봐야 한다.

## 덧붙임: 논문값은 재현되지만 시드 하나의 결과다

2022-06 코드에서 시드만 바꾼 결과다(MSE).

| 칸 | 시드 2021 (논문) | 5개 시드 범위 | 평균 | 표준편차 |
|---|---|---|---|---|
| ETTh1 192 | 0.4055 | 0.4051 ~ 0.4085 | 0.4069 | 0.0015 |
| ETTh1 720 | 0.4719 | 0.4698 ~ 0.4888 | 0.4791 | 0.0084 |
| ETTh2 720 | 0.6054 | 0.6054 ~ 0.7350 | 0.6860 | 0.0530 |
| ETTm2 720 | 0.3971 | 0.3824 ~ 0.4329 | 0.4063 | 0.0187 |
| 환율 336 | 0.3048 | 0.2812 ~ 0.3475 | 0.3146 | 0.0251 |
| 환율 720 | 0.6432 | 0.6432 ~ 1.0521 | 0.8101 | 0.1641 |

- ETTh1 192처럼 안정적인 칸은 시드에 거의 흔들리지 않는다.
- ETTh2 720과 환율 720에서는 시드 2021이 5개 중 가장 좋은 값이다. 논문 숫자는 정확히 재현되지만, 이 칸들에서는 운이 좋은 쪽의 한 번이다.
- 이 칸들은 1절에서 "쓰지 않는 층" 하나로 결과가 크게 바뀐 칸과 같다. 난수 순서에 민감한 칸이라는 뜻이다.

학습 없이 최소제곱으로 구한 해(끝까지 수렴한 선형 모델)와 비교하면 이유가 보인다.

| 칸 | 수렴한 해 | 논문 |
|---|---|---|
| ETTh1 96 / 192 / 336 / 720 | 0.370 / 0.404 / 0.433 / 0.471 | 0.375 / 0.405 / 0.439 / 0.472 |
| ETTm1 96 / 192 / 336 / 720 | 0.299 / 0.334 / 0.368 / 0.423 | 0.299 / 0.335 / 0.369 / 0.425 |
| ETTh2 720 | 0.741 | 0.605 |
| ETTm2 720 | 0.458 | 0.397 |
| 환율 720 | 1.100 | 0.643 |

ETTh1과 ETTm1에서는 논문값이 수렴한 해와 거의 같다. ETTh2, ETTm2, 환율의 긴 구간에서는 수렴한 해가 논문값보다 훨씬 나쁘다. 이 칸들의 논문값은 끝까지 학습한 결과가 아니라 중간에 멈춘 결과이고, 어디서 멈추느냐는 초기화·학습률·난수 순서에 달려 있다. 이 해석은 수치와 맞지만, 학습 경로를 직접 추적해 확인한 것은 아니다.

원자료: `seeds_june2022_code.csv`, `closed_form_ols.csv`

## 덧붙임: NLinear와 Linear 재현 (2022-08 코드)

NLinear와 Linear는 2022-08 코드에서 처음 들어왔다. 그 코드와 스크립트로 ETT 4종과 환율을 돌렸다.

| 모델 | 칸 수 | 소수 셋째 자리까지 일치 | 차이 0.002 이내 |
|---|---|---|---|
| NLinear | 20 | 14 | 16 |
| Linear | 20 | 16 | 16 |

일치하지 않은 칸은 NLinear의 ETTh2 96·192, ETTm2 720, 환율 720과 Linear의 ETTh2 96·192·336, ETTm2 720이다. DLinear에서 학습률 문제가 있던 데이터(ETTh2, ETTm2, 환율)와 겹친다. 원인은 아직 확인하지 않았다(`open_problems.md` 4번).

원자료: `aug2022_code_linear_nlinear_dlinear.csv`
