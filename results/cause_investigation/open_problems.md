# 아직 설명하지 못한 차이: 문제 정의

확인된 원인은 `confirmed_causes.md`에 있다. 이 문서는 여러 방법으로 확인한 뒤에도 남은 차이를, 다음 사람이 이어서 볼 수 있게 정리한다.

- 작성일: 2026-11-13

## 한눈에 보기

| 번호 | 문제 | 차이 크기 | 상태 |
|---|---|---|---|
| 1 | Traffic 192·336·720 | MSE 0.001~0.002, MAE 0.003~0.004 | 유력한 가설 있음. 실행만 남음 |
| 2 | 단변량 ETTh2 96의 정확한 설정 | 후보 2개가 모두 일치 | 공개 정보로는 가릴 수 없음 |
| 3 | 다변량 ETTm2 96 | MSE 0.0007 | 원인 모름 |
| 4 | NLinear 환율 720 | MSE 0.01~0.09 | 학습률로 풀리지 않음 |

이전 판의 5번("논문값은 중간에 멈춘 결과"라는 해석)은 학습 곡선으로 확인해 `confirmed_causes.md` 9절로 옮겼다. 이전 판 4번의 NLinear·Linear 불일치 8칸 중 7칸은 학습률로 설명되어 `confirmed_causes.md` 8절로 옮겼다. 순서 섞기 실험(Table 5)의 설정 차이는 입력 길이로 확인해 `confirmed_causes.md` 10절로 옮겼다.

## 1. Traffic 192·336·720

### 현상

2022-06 코드와 스크립트(학습률 0.05, 배치 16, 최대 10 epoch)로 돌린 값이 논문보다 조금 높다.

| T | 재현 MSE / MAE | 논문 MSE / MAE |
|---|---|---|
| 96 | 0.4112 / 0.2839 | 0.410 / 0.282 |
| 192 | 0.4245 / 0.2912 | 0.423 / 0.287 |
| 336 | 0.4375 / 0.2989 | 0.436 / 0.296 |
| 720 | 0.4680 / 0.3180 | 0.466 / 0.315 |

### 지금까지 확인한 것

- 96은 최대 epoch를 30으로 늘리면 0.4103 / 0.2822로 논문과 일치한다.
- 시드(2021, 2022, 2023), GPU와 CPU, 데이터 파일은 원인이 아니다.
- Traffic 스크립트는 첫 공개 이후 바뀐 적이 없다.

### 가설

192·336·720도 96과 같이 10 epoch보다 길게 학습한 값이다.

### 확인 방법

2022-06 코드에서 `--train_epochs 30`을 붙여 세 칸을 돌린다. 예측 길이가 길면 한 실행이 메모리를 5GB 넘게 써서 CPU 전용 환경(8GB)에서는 죽었다. Colab T4에서 돌려야 한다.

### 판정 기준

세 칸 모두 MSE와 MAE가 소수 셋째 자리까지 논문과 같으면 해결. 하나라도 다르면 Traffic은 "96만 확인"으로 남긴다.

## 2. 단변량 ETTh2 96의 정확한 설정

### 현상

스크립트 설정(학습률 0.005, 배치 32)으로는 0.1329 / 0.2808이 나온다. 논문은 0.131 / 0.279다.

### 지금까지 확인한 것

학습률 6개와 배치 3개를 조합한 18가지를 돌렸다. 논문과 두 지표 모두 일치하는 조합이 둘이다.

| 학습률 | 배치 | MSE | MAE |
|---|---|---|---|
| 0.05 | 32 | 0.1308 | 0.2792 |
| 0.005 | 16 | 0.1311 | 0.2794 |

PyTorch 1.9.0에서도 스크립트 설정의 결과는 같다(0.1329).

### 왜 더 못 가는가

논문은 소수 셋째 자리까지만 적는다. 두 후보가 그 자리까지 같아서 실험으로는 가릴 수 없다. 같은 스크립트의 192·336·720은 스크립트 설정 그대로 논문과 일치하므로, 다른 칸에서 힌트를 얻을 수도 없다.

### 남은 방법

저자에게 GitHub issue로 묻는다. 물을 내용: "단변량 ETTh2 96(Table 9)을 만들 때 쓴 학습률과 배치 크기."

## 3. 다변량 ETTm2 96

### 현상

2022-06 코드와 스크립트(학습률 0.001, 배치 32)로 0.1677 / 0.2598이 나온다. 반올림하면 0.168 / 0.260이고, 논문은 0.167 / 0.260이다. MSE만 0.0007 다르다.

### 지금까지 확인한 것

| 학습률 | MSE | MAE |
|---|---|---|
| 0.05 | 0.1933 | 0.2917 |
| 0.01 | 0.1681 | 0.2605 |
| 0.005 | 0.1688 | 0.2644 |
| 0.001 (스크립트) | 0.1677 | 0.2598 |
| 0.0005 | 0.1676 | 0.2566 |
| 0.0001 | 0.1645 | 0.2573 |

MSE 0.167과 MAE 0.260을 동시에 주는 학습률은 없다.

### 가능한 설명 (모두 미확인)

- 논문이 반올림이 아니라 버림으로 적었다. 0.1677을 버리면 0.167이다. 다만 다른 칸들은 반올림과 맞아서, 이 칸만 버림일 이유가 없다.
- 배치 크기가 달랐다. 배치는 아직 바꿔 보지 않았다.

### 확인 방법

배치 8, 16, 64로 돌려 본다. 그래도 안 맞으면 "반올림 수준의 차이, 원인 모름"으로 닫는다.

## 4. NLinear 환율 720

### 현상

2022-08 코드와 스크립트(학습률 0.0005, 배치 32)로 0.9430 / 0.7283이 나온다. 논문은 1.033 / 0.780이다. 재현값이 오히려 더 좋다.

### 지금까지 확인한 것

학습률 6개(배치 32)를 돌렸다. MSE와 MAE를 동시에 맞추는 값이 없다.

| 학습률 | MSE | MAE |
|---|---|---|
| 0.05 | 1.0412 | 0.7634 |
| 0.01 | 1.0140 | 0.7583 |
| 0.005 | 0.9935 | 0.7544 |
| 0.001 | 0.9707 | 0.7399 |
| 0.0005 (스크립트) | 0.9430 | 0.7283 |
| 0.0001 | 0.8831 | 0.7029 |

같은 칸의 DLinear(환율 720)는 9절에서 본 것처럼 학습 초반 epoch에서 멈춘 값이고 시드에 크게 흔들린다(0.643~1.052). NLinear도 같은 성질이라면 학습률 하나로 맞출 수 없는 것이 자연스럽다.

### 확인 방법

1. 배치 8, 16으로 학습률을 다시 훑는다.
2. 시드 5개를 돌려 1.033 / 0.780이 시드 범위 안에 드는지 본다.
3. 30 epoch 학습 곡선에서 어느 epoch가 논문값에 가까운지 본다.

### 판정 기준

어떤 설정에서 두 지표가 소수 셋째 자리까지 맞으면 해결. 시드 범위 안에만 들면 "시드에 민감한 칸이라 정확한 설정을 특정할 수 없음"으로 닫는다.
