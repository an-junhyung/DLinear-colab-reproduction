## Table 8: 효율 (전력, 입력 96, 예측 720, 배치 1)

| 모델 | 파라미터 | 논문 | 추론 시간 (T4) | 논문 (Titan XP) |
|---|---|---|---|---|
| DLinear | 139,680 | 139.7K | 0.69ms | 0.4ms |
| Transformer | 11.67M | 13.61M | 8.4ms | 26.8ms |
| Informer | 12.45M | 14.39M | 12.5ms | 49.3ms |
| Autoformer | 12.14M | 14.91M | 23.4ms | 164.1ms |
| FEDformer | 17.91M | 20.68M | 47.7ms | 40.5ms |

- DLinear의 파라미터 수는 논문과 같다. Transformer 네 종은 논문보다 195만~277만 개 적다.
- 차이의 원인을 확인했다(2026-11-22). 변수 수를 전력의 321개가 아니라 교통의 862개로 놓으면 논문 숫자가 나온다: Transformer 13,605,214(논문 13.61M), Informer 14,393,182(14.39M), FEDformer 20,681,582(20.68M). Autoformer는 CPU에서 만들 수 없어 직접 세지 못했지만, FEDformer와 늘어나는 양이 같다고 보면 14,914,398(14.91M)이다. 입력과 출력의 변수 수가 임베딩과 마지막 층의 크기를 정하기 때문이다. 논문 Table 8은 전력 데이터라고 적혀 있지만, Transformer 쪽 파라미터 수는 변수 862개로 센 값이다. DLinear는 모든 변수가 가중치를 같이 쓰므로 변수 수와 무관하게 139,680개다.
- 추론 시간은 GPU와 측정 방식이 달라 직접 비교할 수 없다. DLinear가 12~69배 빠르다는 방향은 같다. 가장 느린 모델은 논문에서는 Autoformer, 여기서는 FEDformer다.
- 메모리는 추론 한 번의 텐서 최대 사용량(13~151MiB)만 쟀다. 논문의 687~7,607MiB와는 재는 대상이 다르다. 계산량(MACs)은 재지 않았다.
