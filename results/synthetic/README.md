# 합성 데이터 실험

재현에서 본 두 현상을, 직접 만든 시계열로 따로 떼어 확인한 실험이다. 코드는 `scripts/synthetic.py` 하나이고 CPU에서 30초 안에 끝난다.

데이터 처리는 저장소의 custom 로더와 같게 했다. 시간 순서로 70 / 10 / 20 % 분할, 학습 구간의 평균과 표준편차로 표준화, 입력 L개와 출력 T개 창을 만든다. "학습 없이 푼 해"는 최소제곱(아주 작은 ridge 1e-3)으로 푼 선형회귀다.

## A. 수준이 바뀌면 Linear만 무너진다

시계열 = 하루 주기 사인파(진폭 1) + AR(1) 잡음(φ 0.9, σ 0.3) + 수준. 수준은 학습·검증 구간에서 +d/2 근처를 맴돌다가 테스트 구간에서 −d/2 근처로 옮겨 간다(평균 회귀 계수 0.01, 걸음 잡음 0.05). L = 336, T = 96.

**수준 차이 d에 따른 테스트 MSE** (학습 없이 푼 해, 시드 3개 평균, `level_shift_scan.csv`)

| d | Linear | NLinear |
|---|---|---|
| 0 | 0.520 | 0.546 |
| 1 | 0.919 | 0.546 |
| 2 | 2.125 | 0.584 |
| 3 | 4.138 | 0.657 |
| 4 | 6.959 | 0.767 |
| 6 | 15.023 | 1.096 |

- 수준 차이가 없으면 Linear가 조금 더 좋다(0.520 vs 0.546). 논문 Table 2에서 전력처럼 안정적인 데이터에서 둘이 비슷한 것과 같은 방향이다.
- 차이가 커질수록 Linear의 오차는 빠르게 커지고 NLinear는 거의 그대로다.

**epoch별 곡선** (d = 3, Adam, 학습률 0.005, 매 epoch 절반으로 줄임, 배치 32, Linear는 1/L 초기값, `level_shift_epochs.csv`)

- 학습 전(1/L 초기값, 입력 평균을 그대로 내놓는 상태)의 테스트 MSE는 두 모델 모두 1.249.
- Linear: 검증 MSE는 1.05 → 0.51로 계속 줄지만 테스트 MSE는 1 epoch에 8.47로 뛰고 5.22로 수렴한다. 수렴값은 학습 없이 푼 해(5.22)와 같다.
- NLinear: 테스트 MSE 0.80 → 0.75로 수렴, 학습 없이 푼 해 0.75와 같다.
- 즉 학습 데이터에 끝까지 맞출수록 Linear는 학습 구간의 수준으로 예측을 끌어당겨 테스트에서 틀린다. ETTh2 720, 환율 720에서 본 "학습 초반 값이 더 좋다"와 같은 구조다. 다만 여기서는 검증 구간이 학습 구간과 같은 수준이라, 조기 종료가 초반에 멈춰 주지는 않는다.

## B. 입력이 주기를 담아야 쓸 수 있다

시계열 = 평일에는 진폭 1, 주말에는 진폭 0.3인 하루 주기 + 평일에만 +0.8 + AR(1) 잡음(φ 0.9, σ 0.3). 수준 변화 없음. T = 96, Linear는 학습 없이 푼 해.

| L | 24 | 48 | 96 | 144 | 168 | 192 | 336 | 504 | 720 |
|---|---|---|---|---|---|---|---|---|---|
| 테스트 MSE | 0.640 | 0.610 | 0.559 | 0.515 | 0.504 | 0.501 | 0.483 | 0.475 | 0.477 |

- 1주(168시간)까지는 입력이 길어질수록 크게 줄고, 그 뒤로는 완만하다.
- L = 336의 가중치 행렬(`lookback_weekly_W336.npy`, 예측 시점 × 입력 시점)에는 168시간, 336시간 간격의 대각선 줄무늬가 보인다. 논문 Figure 7, 재현 23번 슬라이드와 같은 모양이다.

## 한계

직접 설계한 데이터라서, 현상이 "이런 구조라면 이렇게 된다"는 것을 보일 뿐 실제 데이터에서 같은 크기로 나타난다는 근거는 아니다. 수준 차이 d, 잡음 크기 같은 값은 그림이 잘 보이도록 고른 것이다.
